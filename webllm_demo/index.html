WebLLM-Driven AFL++ Seed Generator Demo

This page runs a small language model in the browser using WebLLM and asks it to generate hexadecimal AFL++ seed inputs for the Open5GS NAS 5G Registration Request harness.

The output should be saved as webllm_generated_seeds.txt, then converted into binary AFL++ seed files using scripts/import_webllm_hex_seeds.py.
